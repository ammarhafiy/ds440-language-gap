# Pilot Questions

`questions.csv` holds the 20 hand-written pilot questions from the first version of the project design (10 NBA, 10 Malaysia Super League), with English versions and my own Malay translations.

After feedback from Leona on 8 October 2026, the main dataset will come from existing data at a much larger scale (MKQA and questions generated from Wikidata) instead of hand-written questions. These 20 questions are kept for testing the data collection and scoring scripts before running the full dataset.
