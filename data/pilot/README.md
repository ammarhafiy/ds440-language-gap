# Pilot Questions (week 1, no longer used)

`questions.csv` holds the 20 hand-written pilot questions from the first version of the project design (10 NBA, 10 Malaysia Super League), with English versions and my own Malay translations.

After feedback from Leona on 8 October 2026, the study uses existing data at a much larger scale (questions generated from Wikidata, plus MKQA) instead of hand-written questions. These 20 questions are kept only as a record of the first design. They are not used in the study, because they have no answer keys or fact sentences.

The pilot run of the collection script uses 20 questions sampled from the final question set instead (`--pilot 20` in `scripts/05_collect_responses.py`).
